## 📝 Homework 04 — Needfinding: 3 Interviews + Affinity Diagram (Semester Project Part 1)

Pick a project domain you care about (suggestions for engineers: *how developers verify AI-generated code*, *onboarding to an unfamiliar codebase*, *how on-call engineers triage alerts*, or a non-tech domain you have access to).
Write an interview guide, get **verbal informed consent**, interview **3 people** (20–30 min each), and build an **affinity diagram** (Obsidian Canvas works well).

**Deliverables**

- [ ] Project domain + 1-paragraph rationale
- [ ] Interview guide (warm-up, 8–10 open questions, probes)
- [ ] Consent script you read aloud
- [ ] Anonymized notes per participant (P1–P3) with verbatim quotes
- [ ] Affinity diagram + 3–5 themes, each backed by ≥ 2 quotes

**Rubric (/15)**

| Criterion | Points |
|---|---|
| Open, non-leading interview questions | /3 |
| Ethical handling: consent + anonymization | /3 |
| Rich, verbatim evidence from 3 participants | /3 |
| Themes emerge from data (not assumptions) | /4 |
| Clear write-up | /2 |

**Grading:** ≥ 13 = A · ≥ 10 = B · below that → redo the weakest criterion before moving on.
