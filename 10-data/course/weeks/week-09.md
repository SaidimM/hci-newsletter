## 📝 Homework 09 — 5-User Think-Aloud Study (Semester Project Part 5)

Run a formative usability study of your Week 8 prototype with **5 new participants** (P8–P12).
Each session: consent → 2–3 tasks with think-aloud → SUS questionnaire → short debrief.

**Deliverables**

- [ ] Study protocol (tasks, success criteria, script)
- [ ] Per-participant notes + task success/time
- [ ] SUS scores (individual + mean) computed correctly
- [ ] Usability issue list with severity + frequency
- [ ] Top 3 fixes → define a **Variant B** for Week 10

**Rubric (/15)**

| Criterion | Points |
|---|---|
| Protocol is clear and repeatable | /3 |
| 5 sessions run with good think-aloud prompting | /3 |
| SUS computed correctly and interpreted | /3 |
| Issues prioritized by severity × frequency | /3 |
| Variant B is well-motivated | /3 |

**Grading:** ≥ 13 = A · ≥ 10 = B · below that → redo the weakest criterion before moving on.
