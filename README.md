# HCI Newsletter Collector & PhD Prep Hub

A curated repository and workspace for an engineer learning Human-Computer Interaction (HCI) from the ground up, preparing for PhD applications, and learning in public across social media.

---

## 📂 Directory Layout

```
hci-newsletter-collector/
├── README.md                           # This overview and workflow guide
├── roadmap.md                          # The SWE -> HCI PhD strategy & roadmap
├── curated-sources/
│   └── hci-newsletters-and-feeds.md   # Newsletters, lab pages, conferences, RSS
├── reading-list/
│   └── 00-starter-curriculum.md        # Foundations, Methods, Systems, GenAI
├── social-notes/                       # Stored notes, threads, and social drafts
├── templates/
│   ├── paper-note-template.md          # Structured breakdown for academic papers
│   └── social-post-template.md         # Templates for X/Twitter, Substack, LinkedIn
└── archive/                            # Archived newsletters and past digests
```

---

## 🚀 Weekly Learning & Publishing Workflow

```
       [ 1. Collect ]
  RSS, arXiv cs.HC, Lab Blogs, Newsletters
              │
              ▼
       [ 2. Synthesize ]
  Read 1 paper / topic using templates/paper-note-template.md
              │
              ▼
       [ 3. Publish & Connect ]
  Convert note to social post using templates/social-post-template.md
              │
              ▼
       [ 4. Build Portfolio ]
  Accumulate public notes, citations, and prototype ideas for PhD SOP
```

---

## 🎯 Primary Goals
1. **Master HCI core foundations**: Bridge engineering systems logic with human cognitive models and empirical user study methodologies.
2. **Build an online academic footprint**: Consistently share insights and critiques, attracting future academic advisors and peers.
3. **Formulate a PhD research direction**: Pinpoint high-impact intersection areas (e.g., Systems HCI, Human-AI collaboration, Developer Tooling).
