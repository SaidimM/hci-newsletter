### Usability 

 Effectiveness, Efficiency, Satisfaction with which specified users achieve specified goals in articular environment. 
 
### Usability/ User Experience goals

- Set Goals early & later use to measure progress
- Goals often have tradeoffs, so prioritize

### User centered Design
- Know thy user 
	- this is the core of design, don't design by your likes, understand the user, what user need, what user think, what user uses tools.
- Cognitive abilities - when developing, must consider psychological limitation
	- Perception - 
	- Physical manipulation 
	- Memory  - human memory has limitations, less let user remember in design
- **Organizational / educational job abilities**
- Keep users involve throughout - keep them in design process

- Observe existing practice for inspiration
- Make sure key question answered
- Ethical questions in design - underserved communities
